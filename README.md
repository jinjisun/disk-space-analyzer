# 磁盘空间分析器 (Disk Space Analyzer)

一个轻量、纯本地的 Windows 磁盘空间可视化工具，帮你快速找到"文件大头"在哪里，方便清理。

## 功能

- **切片树图**：文件夹/文件面积越大，占用空间越多，一眼看出大头。
- **下钻浏览**：点击文件夹进入，点击文件直接打开所在位置。
- **文件夹列表**：当前目录下子项按大小排序。
- **最大文件列表**：整次扫描中最大的 300 个文件。
- **一键删除到回收站**：可恢复，不误删。
- **停止 / 返回上级 / 根目录 / 刷新** 等导航。

## 运行环境

- Windows
- Python 3.x（自带 tkinter 即可，无需任何第三方依赖）

## 使用方法

双击 `磁盘空间分析器.bat` 启动，选择盘符或文件夹，点击「扫描」即可。

> 提示：扫描大目录（如整个 C 盘）首次可能耗时 1~3 分钟，属正常现象。

## 文件说明

- `磁盘空间分析器.bat` — 启动脚本（双击运行）
- `disk_space_analyzer.pyw` — 主程序（无控制台窗口）
